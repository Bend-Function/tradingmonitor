# tradingmonitor

自适应看盘应用的前端 Demo，支持手机、平板、电脑和投影设备。

## 运行

需要 Bun 1.4 或更新版本。项目依赖安装并构建后，由一个静态服务提供页面：

```bash
bun install
bun run check
bun test
bun run build
bun run start
```

默认监听 `0.0.0.0:8080`，可通过已有 VPN 访问当前机器的地址。
`HOST` 和 `PORT` 可配置，例如 `PORT=8081 bun run start`。
`0.0.0.0` 表示所有网络接口，应用不负责配置 VPN 或防火墙。

## 演示范围

- 最多六张独立图表，容器可拖动并调整宽高比例。
- 模拟动态 K 线、成交量，以及前端计算的 SMA20、EMA50、RSI14、CCI20。
- 自选、订单簿和累计深度是独立容器，可隐藏和恢复；可添加多个盘口，各自选择标的和市场。
- 研究图默认占整列，两张纯 K 线可上下共用一列。
- 暂停/恢复、明暗主题、面板放大、工作区保存及命名蓝图。
- 自适应窄屏和宽屏；1920×1080 是支持的尺寸之一。

## 自定义蓝图

1. 在宽屏点击“编辑布局”，拖动容器标题栏的把手调整位置，拖动右下角调整宽高；完成后点击“锁定布局”。
2. 点击某张图后，在工具栏选择其指标。启用 RSI 或 CCI 会将该图扩展为整列高度，并避让相邻容器。
3. 点击容器右上角的隐藏按钮，从工作区顶部恢复栏可以找回。添加盘口后，用它自己的下拉框选择标的和市场。
4. 打开右上角“工作区设置”，可以保存当前工作区，或输入名称保存一张蓝图，再随时应用。

手机及较窄窗口使用单列预览，不会改写宽屏容器的位置和尺寸；标的、指标及显隐仍可调整。
切换图表标的或周期时会重新适配价格轴，也可以使用图表上的“重置价格比例尺”按钮。

行情全部为模拟数据。当前版本没有接入币安、NautilusTrader、账户或交易功能。
保存的数据仅保存在当前浏览器，不会同步到其他设备；清理站点数据会移除保存的设置。
本 Demo 的指标在前端计算，用来展示交互和接入后的表现，不代表已验证你的自研因子。

图表由 [TradingView Lightweight Charts](https://www.tradingview.com/) 提供。
